# 翻译服务配置与协议适配实现说明

状态：服务档案、密钥安全存储和 OpenAI 兼容协议 adapter 已实现；尚未接入持久化批量翻译任务。

## 服务档案

- 入口位于应用设置，设置页与后续工作台选择器共用 `TranslationServiceRepository` 数据源。
- schema v4 的 `translation_service_profiles` 保存服务名、稳定 ID、协议 ID、根地址、模型 ID、翻译提示词、启用状态、修订号与 `secretRef`。Room 不保存 API Key。
- 当前只有 `openai-compatible-chat-v1` 协议档案；设置服务档案不等于支持任意服务协议。还没有传统机器翻译服务模板、Gemini 或 Anthropic adapter。
- 模型目录可在保存档案前获取，也可手动填写模型 ID。服务没有模型目录时仍可保存；模型列表可用不保证模型有翻译权限。

## 密钥与备份

- API Key 使用翻译域独立 Android Keystore AES/GCM 别名，加密后写入 `translation_service_secrets.xml`。密文按服务 ID/修订引用，替换密钥不会覆盖旧修订密文。
- `translation_service_secrets.xml` 已加入 Android Auto Backup 与 API 31+ cloud backup/device-transfer 排除规则。Room 服务档案只含 `secretRef`，不含密钥。
- 解密失败返回 `SECRET_UNAVAILABLE` 并保留原密文。用户需重新输入密钥；换机或恢复备份不能恢复 Keystore 密钥。
- 服务档案删除会删除该服务 ID 前缀下的密文；当前持久化翻译任务尚未实现，因此还没有任务引用保留/清理策略。

## OpenAI 兼容 adapter

- `GET <baseUrl>/models` 获取模型目录；`POST <baseUrl>/chat/completions` 发送非流式 Chat Completions 请求。允许根地址包含 `/v1` 等路径前缀。
- 仅支持 HTTP/HTTPS 地址，拒绝 userinfo、query、fragment 与点路径段；API Key 只经 Bearer Authorization header 发送，不经 URL query。
- 翻译域有独立 OkHttp transport：连接/读/写/整体请求超时有上限、自动重定向关闭、连接失败重试关闭、响应体上限 2 MiB；请求超时、TLS、网络、鉴权、限流、额度、模型、服务端与无效响应映射为类型化错误。`Retry-After` 秒数保留在错误对象中，当前尚无任务重试调度器。
- adapter 将请求限制为每批最多 50 条、512 KiB；响应按稳定条目 ID 对齐。部分有效条目可与缺失 ID、重复 ID、未知 ID分开表达；控制码、格式占位符和换行损坏的条目不返回成功结果。
- adapter 已有合成 JSON 回归和 HTTP Call 取消回归，但没有连接真实服务商验证。兼容协议不保证所有服务商实现完全一致。

## 尚未接入的能力

- 没有持久化翻译任务、工作台服务选择器、翻译进度/失败条目 UI、批次恢复或重试调度。
- 没有项目术语表、MTool JSON exporter、AI 校对与人工条目编辑确认。
- AI 校对默认范围和传统机器翻译模板清单仍是待产品确认事项，本实现不作默认决策。
- 尚未在 Android 设备验证 Keystore 加密/丢失、备份恢复密钥提示、SAF 导出或手机/平板布局；尚未完成真实 OpenAI-compatible API 端点验收。
