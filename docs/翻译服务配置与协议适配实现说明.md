# 翻译服务配置与协议适配实现说明

状态：服务档案、密钥安全存储、OpenAI-compatible Chat Completions 与 Gemini Interactions API v1 adapter、持久化批量翻译和 AI 校对任务已实现；真实供应商及设备验收尚未完成。

## 服务档案

- 入口位于应用设置，设置页与后续工作台选择器共用 `TranslationServiceRepository` 数据源。
- schema v6 的 `translation_service_profiles` 保存服务名、稳定 ID、协议 ID、根地址、模型 ID、翻译/校对提示词、启用状态、修订号与 `secretRef`。Room 不保存 API Key。
- 当前实现 `openai-compatible-chat-v1` 与 `gemini-interactions-v1` 两种独立协议，两个 adapter 均声明 `TRANSLATE` 与 `AI_PROOFREAD` 能力；设置服务档案不等于支持任意服务协议。还没有传统机器翻译服务模板或 Anthropic adapter。
- 模型目录可在保存档案前获取，也可手动填写模型 ID。服务没有模型目录时仍可保存；模型列表可用不保证模型有翻译权限。

## 密钥与备份

- API Key 使用翻译域独立 Android Keystore AES/GCM 别名，加密后写入 `translation_service_secrets.xml`。密文按服务 ID/修订引用，替换密钥不会覆盖旧修订密文。
- `translation_service_secrets.xml` 已加入 Android Auto Backup 与 API 31+ cloud backup/device-transfer 排除规则。Room 服务档案只含 `secretRef`，不含密钥。
- 解密失败返回 `SECRET_UNAVAILABLE` 并保留原密文。用户需重新输入密钥；换机或恢复备份不能恢复 Keystore 密钥。
- 服务档案删除会清理不再被其它档案或任务快照引用的密文；正在等待任务引用的密钥版本仍保留。任务结束或取消后按持久化引用集合清理。

## OpenAI 兼容 adapter

- `GET <baseUrl>/models` 获取模型目录；`POST <baseUrl>/chat/completions` 发送非流式 Chat Completions 请求。允许根地址包含 `/v1` 等路径前缀。
- 仅支持 HTTP/HTTPS 地址，拒绝 userinfo、query、fragment 与点路径段；API Key 只经 Bearer Authorization header 发送，不经 URL query。
- 翻译域有独立 OkHttp transport：连接/读/写/整体请求超时有上限、自动重定向关闭、连接失败重试关闭、响应体上限 2 MiB；请求超时、TLS、网络、鉴权、限流、额度、模型、服务端与无效响应映射为类型化错误。`Retry-After` 秒数保留在错误对象中；重试由用户显式发起，不对鉴权等不可重试错误自动循环。
- adapter 将请求限制为每批最多 50 条，后台任务每批最多 30 条；响应按稳定条目 ID 对齐。部分有效条目可与缺失 ID、重复 ID、未知 ID分开表达；控制码、格式占位符和换行损坏的条目不返回成功结果。AI 校对建议与问题、条目复核状态和检查点在同一 Room 事务内提交，不覆盖当前译文。
- adapter 已有合成 JSON 回归和 HTTP Call 取消回归，但没有连接真实服务商验证。兼容协议不保证所有服务商实现完全一致。

## Gemini Interactions adapter

- TYN 协议 ID 为 `gemini-interactions-v1`，使用 Google 推荐的新项目 Interactions API v1：`POST https://generativelanguage.googleapis.com/v1/interactions`。请求使用 JSON `response_format` schema，API Key 仅通过 `x-goog-api-key` 请求头发送，正文显式设置 `store=false` 与 `stream=false`。
- 模型目录使用 Gemini API 的 `GET /v1beta/models?pageSize=1000`，按 `nextPageToken` 分页，只展示声明支持 `generateContent` 的模型 ID；用户仍可手动输入模型 ID。模型目录不保证某个账户/模型具备实际生成权限，失败仍由任务映射为类型化错误。
- 档案根地址固定为 `https://generativelanguage.googleapis.com`，只接受该官方 HTTPS host，拒绝 query、fragment、userinfo、自定义端口和非根路径，避免 API Key 被转发给任意端点。Vertex AI 使用不同端点与鉴权协议，Gemini 自定义代理也不在本 adapter 范围。
- 翻译和校对分别传输提示词、语言与带稳定条目 ID 的 JSON 项目；校对使用 `proofreadingPrompt`，不会误用翻译提示词。响应从 `steps` 中读取 `model_output` 文本，交由共享结构化响应解析器检查缺失/重复/未知 ID、失败条目、占位符/控制码与换行。两种能力均不自动重试；取消由翻译域 OkHttp transport 取消底层 Call。
- JVM 合成回归覆盖模型目录分页、模型能力过滤、固定路径/请求头/`store=false`、翻译/校对提示词分流、结构化结果和鉴权错误；该回归不代表真实 Gemini 端点兼容性验收。

## 尚未接入的能力

- 当前没有自动重试调度器；用户可继续/重试未完成或失败条目。没有 Anthropic adapter 或传统机器翻译服务模板。
- AI 校对范围默认值仍待产品确认；工作台每次让用户明确选择「规则命中条目」或「全部已翻译条目」，未固化默认值。当前没有扩展引擎提取器。
- 本地规则目前仅覆盖空译文、格式占位符/控制码和换行。当前代码没有应用内运行时译表加载与交付通路，MTool 文件导出尚未通过真实游戏显示验收。
- 尚未在 Android 设备验证 Keystore 加密/丢失、备份恢复密钥提示、SAF 导出或手机/平板布局；尚未连接真实 OpenAI-compatible 或 Gemini 服务验证端点兼容性、鉴权、模型列表、取消与限流行为。
