# 翻译服务配置与协议适配实现说明

状态：服务档案、安全密钥存储、两类服务选择、七个在线机器翻译 adapter、OpenAI-compatible Chat Completions、Gemini Interactions v1，以及持久化翻译/AI 校对任务已接入。JVM 协议回归通过；真实供应商账号、真实游戏文本效果和 Android 设备网络行为尚未验收。

## 服务档案与类别

- 设置页与工作台共用 `TranslationServiceRepository`。档案有两类：机器翻译和 AI 翻译；服务能力由 adapter 声明，只有启用、配置完整且能力匹配的档案才进入任务选择器。
- 机器翻译目前只接入必应、小牛、火山引擎、Azure Translator、DeepL、百度翻译和腾讯云 TMT。其它机器翻译、离线模型和本地 AI 暂未接入。机器翻译 adapter 只声明 `TRANSLATE`，不会进入 AI 校对选择器。
- OpenAI-compatible Chat Completions 和 Gemini Interactions v1 是 AI 翻译服务，均可声明 `TRANSLATE` 与 `AI_PROOFREAD`。设置自定义地址不等于支持任意服务协议；Gemini 仍只连接官方 Developer API 固定 HTTPS 地址，不支持 Vertex AI 或 Gemini 自定义代理。
- 机器翻译使用固定供应商 HTTPS 主机，不提供任意 URL。机器翻译没有模型 ID；AI 档案保留模型目录获取和手动填写。

## 在线机器翻译协议

| 服务 | TYN 协议 ID | 请求协议与认证 | 单批上限 |
| --- | --- | --- | --- |
| 必应 | `bing-translator-web-v1` | `cn.bing.com/Translator` 网页令牌 + `ttranslatev3` 表单请求；不需要 API Key | 1 条 |
| 小牛 | `niutrans-translation-v1` | `NiuTransServer/translation` JSON POST；API Key 放请求体 | 1 条，单条不超过 5,000 字符 |
| 火山引擎 | `volcengine-translate-text-v1` | `TranslateText`，`2020-06-01`；AK/SK 按 HMAC-SHA256 签名 | 16 条，合计不超过 5,000 字符 |
| Azure Translator | `azure-translator-v3` | Translator v3.0 `POST /translate`；Key 使用请求头，区域资源可填 Region 请求头 | 20 条，合计不超过 45,000 字符 |
| DeepL | `deepl-translate-v2` | API v2 `POST /v2/translate`；`DeepL-Auth-Key` 请求头 | 30 条，JSON 请求体不超过 128 KiB |
| 百度 | `baidu-translate-vip-v1` | 通用文本翻译 `POST` 表单；`appid + q + salt + secretKey` 计算 MD5 签名，原始密钥不发送 | 1 条，单条不超过 5,000 字符 |
| 腾讯云 | `tencent-tmt-text-translate-v1` | TMT `TextTranslate`，版本 `2018-03-21`；SecretId/SecretKey 使用 TC3-HMAC-SHA256 | 1 条，单条不超过 2,000 字符 |

### 稳定性与供应商生命周期

- 必应实现复用网页翻译会话令牌流程，没有稳定的公开翻译 API 协议。页面结构、令牌字段或访问限制变化可能使 adapter 失效；设置页和本说明均标出该限制。此实现来自协议观察，没有复制 StarFlow 源码或引入其依赖。StarFlow 仅作在线/本地翻译流程和供应商范围参考，见 [StarFlow 仓库](https://github.com/xujunjiex/StarFlow)；它使用 LGPL-3.0，因此本项目未集成其源码或二进制。
- 腾讯云已公告：2027-01-31 停止新销售、2027-07-31 停止全面支持和续订、2030-12-31 停止所有服务。公告表示现有付费服务可在有效期内使用；接入仅面向仍有权限的 TMT 账户。见[腾讯云退市公告](https://cloud.tencent.com/announce/detail/2482)。
- DeepL Free/Pro 主机根据 Free Key 的 `:fx` 后缀选择固定官方域名。任务快照只保存配置修订和 `secretRef`，不会复制 API Key。
- 项目术语表随任务快照提供给 adapter。OpenAI-compatible 与 Gemini 请求体携带结构化术语条目；DeepL 以 `context` 字段提供术语上下文。必应、小牛、火山、Azure、百度和腾讯当前协议 adapter 不发送项目术语表，需使用供应商原生术语库的能力尚未接入。

## 密钥与备份

- 服务凭据由翻译域专用 Android Keystore AES/GCM 别名加密，写入 `translation_service_secrets.xml`；该文件排除云备份和设备迁移。Room 档案只保存 `secretRef`，不保存密钥、AK/SK、App ID/Secret、SecretId/SecretKey 或 Azure Region。
- 多字段凭据使用版本化 provider bundle，仅在加密前内存组装；解密失败返回 `SECRET_UNAVAILABLE` 并保留密文。任何服务/任务快照、导出、普通 Room 字段、日志和错误详情都不包含密钥值。
- 用户保存新凭据时需填写完整凭据组；编辑时全部留空会保留现有密文。删除档案后仅清除不再被任务快照引用的密文版本。

## 批次、响应与取消

- `TranslationBatchTaskProcessor` 先遵循全局批次上限，再取各 adapter 的批次上限；单条协议每条文本单独提交检查点。供应商 API 若不接收 TYN 条目 ID，则 adapter 按同一请求内的输入顺序将结果绑定回稳定条目 ID；数组接口检查缺失、额外响应和空译文。对支持 ID 的 AI 协议仍按稳定 ID 检查缺失、重复、未知条目。
- 译文经 `TranslationTextIntegrity` 检查控制码、格式占位符和换行。有效结果与失败条目可部分提交，翻译结果与检查点在同一 Room 事务提交。供应商协议无法提供输入顺序外的稳定 ID，因此不能验证供应商内部是否重排相同文本。
- 翻译域自有 OkHttp transport：连接/读/写/整体超时有上限、自动重定向与连接失败自动重试关闭、响应体上限 2 MiB。协程取消调用底层 `Call.cancel()`；鉴权、限流、额度、服务端和格式错误映射为类型化错误，不做无界自动重试，用户可显式重试失败或未完成条目。
- 传统机器翻译可选能力只有 `TRANSLATE`。AI 校对服务选择器依据 `AI_PROOFREAD` 能力过滤，机器翻译服务不会出现。

## OpenAI-compatible 与 Gemini AI adapter

- OpenAI-compatible adapter 在已配置根地址下调用 `/models` 与 `/chat/completions`；Key 只走 Bearer 请求头。每请求最多 50 条，任务处理器批次上限为 30 条。
- Gemini Interactions adapter 固定 `https://generativelanguage.googleapis.com`，模型目录使用 `/v1beta/models` 分页，交互使用 `/v1/interactions`，Key 只走 `x-goog-api-key` 请求头；请求设置 `store=false` 与 `stream=false`。
- 两者的翻译/校对请求按稳定 ID 返回结构化结果，并验证控制码、占位符和换行。校对建议、问题、条目状态和检查点在同一事务提交，不覆盖当前译文。

## 回归与尚未完成的验收

- JVM 合成回归覆盖七个协议的请求地址/头/体、签名结构、密钥不进 URL、必应令牌与 Cookie 解析、语言/结果映射、能力过滤和格式完整性；共享 transport 的取消回归验证底层 Call 被取消。没有使用真实供应商凭据。
- 这些测试不证明真实接口账号权限、服务端变更、实际语言质量、额度策略或网络地区可用性。必应网页接口尤其需要实网观察；腾讯 TMT 有退市时间表；手机/平板上的服务配置、Keystore 和后台网络行为仍需设备验收。
- 仍未实现自动重试调度、Anthropic/Vertex AI 等额外 AI 协议、其它机器翻译、本地模型、其它引擎 extractor/exporter，或 TYN 应用内运行时译表加载与交付。AI 校对范围默认值仍由工作台逐次要求用户选择，不在本文改成默认决策。
