# 翻译服务配置与协议适配实现说明

状态：服务档案、安全密钥存储、两类服务选择、12 个固定供应商 HTTPS 机器翻译 API adapter、必应网页令牌 adapter，以及有道网页、Google 网页、火山方舟 Responses 和讯飞 OTS 四种新增机器翻译 adapter 已接入；机器翻译协议共 17 种。AI 侧接入 OpenAI Chat Completions、OpenAI Responses API、Gemini Interactions v1、Anthropic Claude Messages API 四种协议与持久化翻译/AI 校对任务。AI 服务列表提供 OpenAI、DeepSeek、Gemini、Claude 四个内置模板，另有独立的自定义 API 入口；已保存的其它 AI 服务档案仍显示在列表中以便管理。Chat 模板复用同一协议 adapter，不表示增加了独立供应商 adapter。默认启用的必应、Google 网页翻译和有道网页排在机器翻译列表前面；13 个机器翻译模板均使用对应品牌图标，OpenAI、DeepSeek、Gemini 和 Claude AI 模板也显示品牌图标。AI 服务档案支持分开的翻译/校对提示词、按协议适配的结构化输出、Chat Completions 输出上限、Gemini 思考等级、OpenAI 官方服务推理强度、自定义请求头与带类型的请求体参数，以及 AI/机器翻译各自的任务执行设置。真实供应商账号、真实游戏文本效果和 Android 设备网络行为尚未验收。

## 服务档案与类别

- 设置页与工作台共用 `TranslationServiceRepository`。档案有两类：机器翻译和 AI 翻译；服务能力由 adapter 声明，只有启用、配置完整且能力匹配的档案才进入任务选择器。
- 已注册机器翻译 adapter 共 17 种：12 个固定供应商 HTTPS API 与 [LunaTranslator 传统 API 清单](https://docs.lunatranslator.org/en/useapis/tsapi.html)对应；另有必应网页令牌、有道网页、Google 网页、火山方舟 Responses 和讯飞 OTS。翻译服务配置页当前提供 13 个内置入口：必应、小牛、火山、Azure、DeepL、百度、腾讯、阿里云、豆包、讯飞、有道网页、Google 网页和 Google Cloud；其余已保存档案仍可管理。LunaTranslator 的其它网页翻译源、离线模型和本地 AI 暂未接入。仅按服务名称或网页入口展示不代表实现了相应协议。机器翻译 adapter 只声明 `TRANSLATE`，不会进入 AI 校对选择器。
- AI 翻译有四种独立协议：OpenAI Chat Completions、OpenAI Responses API、Gemini Interactions v1、Anthropic Claude Messages API；四者都可声明 `TRANSLATE` 与 `AI_PROOFREAD`。自定义 API 协议下拉只提供 Chat Completions、OpenAI Responses 与 Anthropic Messages 三项；Gemini 使用独立官方模板。Chat Completions 地址可编辑，但 adapter 只实现 `/models`、`/chat/completions` 和对应响应结构，不表示兼容任意 API。Responses、Gemini 和 Anthropic adapter 分别固定连接 OpenAI、Google Gemini Developer API 与 Anthropic 官方 HTTPS 主机。Vertex AI、Responses 兼容代理和 Gemini 自定义代理均未接入。
- 机器翻译使用固定供应商 HTTPS 主机，不提供任意 URL。机器翻译没有模型 ID；AI 档案保留模型目录获取和手动填写。

## AI 协议与服务商模板

设置页先按协议分组，再选择服务模板。内置快捷模板仅有 OpenAI、DeepSeek、Gemini、Claude；模板预设显示名称和根地址，模型 ID 与 API Key 不预填，用户可获取模型目录或手动填写。“添加自定义 API”是独立入口，不属于服务商模板；完整配置页提供 Chat Completions、OpenAI Responses 与 Anthropic Messages 三项协议下拉，三项各用独立 adapter，Gemini 使用独立官方模板。已保存档案与当前启用状态仍由 `TranslationServiceRepository` 管理，模板本身不是可供任务选择的服务；以前保存的其它服务档案仍保留并在列表中显示。

| 协议组 | 模板 | 默认根地址 | 说明 |
| --- | --- | --- | --- |
| Chat Completions | OpenAI | `https://api.openai.com/v1` | OpenAI 旧版 Chat Completions 协议。 |
| Chat Completions | DeepSeek | `https://api.deepseek.com` | 服务商模型目录可以获取；模型能力/名称可能变化。 |
| Gemini Interactions | Google Gemini | `https://generativelanguage.googleapis.com` | 固定官方主机，使用 `/v1beta/models` 与 `/v1/interactions`；不接 Vertex AI。 |
| Claude Messages | Anthropic Claude | `https://api.anthropic.com` | 固定 Anthropic 官方主机，使用 [`/v1/models`](https://docs.anthropic.com/en/api/models-list) 与 [`/v1/messages`](https://docs.anthropic.com/en/api/messages)，API Key 经 `x-api-key` 请求头发送。 |

Chat Completions 服务的模型目录、模型参数和响应字段仍可能因模型而有差异。用户可以手动输入模型 ID；即使模型目录可获取，也不代表每个模型支持本工作台的文本批量翻译/校对请求。OpenAI Responses 仍是已实现的独立协议，但不再作为内置快捷模板展示，用户可从“添加自定义 API”入口选择。

默认地址依据服务商公开接口说明整理：[DeepSeek 模型目录](https://api-docs.deepseek.com/api/list-models/)、[OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)、[Anthropic Models API](https://docs.anthropic.com/en/api/models-list)。服务商可能调整模型目录和生命周期；本表是初始地址建议，不构成供应商服务可用性保证。

## 高级提示词与模型选项

- AI 服务编辑器提供独立“高级设置”完整页面。翻译与 AI 校对分别保存系统提示词和用户提示词；用户提示词作为前置说明，随后拼接工作台生成的 JSON 任务数据。结构化数据仍带稳定条目 ID，响应仍须通过 ID、控制码、占位符和换行校验。
- Gemini 思考等级位于服务配置页，仅 Gemini 服务显示；推理强度也位于服务配置页，仅连接 `api.openai.com` 的 OpenAI Chat Completions / Responses 服务显示。DeepSeek 与自定义兼容服务不会显示 OpenAI 专属推理强度选项。
- 高级设置不再分别提供 Temperature、Top P、Frequency/Presence penalty 等采样参数。用户可在自定义请求体中添加协议字段；字段按顶层名称合并，同名字段覆盖 adapter 生成的默认值。Gemini `generation_config` 可作为对象传入。
- Chat Completions 仍提供 Token 上限字段选择（`max_tokens` / `max_completion_tokens`），其数值输入紧跟在字段选择下方，最大值为 1,000,000。其它协议的生成参数由服务商默认值或自定义请求体决定；Claude 在未自定义 `max_tokens` 时仍由 TYN 发送 4096。
- 已存在配置中旧版独立采样参数会在用户打开并保存该服务配置后清除；已启动任务的快照保持原样。Chat 输出上限、OpenAI 官方推理强度、Gemini 思考等级与结构化输出仍按新 UI 保存。
- 不支持 LunaTranslator 的流式输出、上下文缓存/滑窗、预填充或“遇到错误自动换协议”等选项。自定义请求配置增加附加请求头与 JSON 请求体字段：请求头只接受字符串值并拒绝控制字符、重复项及鉴权/传输管理字段；请求体支持字符串、整数、浮点数、布尔值、对象和数组，拒绝重复项以及模型、提示词、存储、流式和结构化输出等协议控制字段。请求头上限 32 项；请求体上限 64 项，每值最多 8,192 字符，总参数最多 32 KiB。
- 结构化输出按协议生成 TYN 条目结果 schema：Chat Completions 使用 response_format，OpenAI Responses 使用 text.format，Gemini Interactions 使用 response_format，Anthropic Messages 使用 output_config。前三者提供关闭、JSON Object 与 JSON Schema，Anthropic 仅提供关闭与 JSON Schema；实际模型/账户能力可能不同，不支持的模式会由供应商拒绝。关闭原生结构化输出时仍会提示模型输出 JSON，TYN 仍按稳定 ID 与文本完整性规则校验响应。

## 结构化输出与自定义请求参数

- 自定义请求头应用于模型目录与翻译/校对请求，自定义请求体字段应用于任务 JSON 请求。参数 JSON 与 API Key 一样由翻译域 Keystore AES/GCM 加密写入 translation_service_secrets.xml；服务档案与任务快照只保存 customParametersRef，执行时再解密。服务配置变更不会改变已启动任务引用的参数版本。
- SmartSub 作为请求设置交互和类型化参数的流程参考；TYN 使用自己的 Room、Keystore 与协议 adapter，不复制 SmartSub 源码或依赖。

## 任务执行设置

- AI 服务和机器翻译服务各有独立的“任务设置”完整页面，参数保存在服务档案中；新任务与 AI 校对任务启动时把设置写入任务快照，之后编辑服务档案不改变已排队或运行任务。
- 机器翻译默认每批 30 条、最多并发 2 个请求、请求间隔 0.2 秒、每分钟请求数 0（不施加本地上限）。批量大小仍取用户设置与 adapter 上限中的较小值。
- AI 默认每批 20 条、并发 1、请求间隔 0 秒，按条目数量拆批，不按 Token 估算拆批。Chat Completions 输出上限在高级设置配置；模型参数可通过自定义请求体填写。
- 当前任务队列仍跨项目串行；AI 并发设置只控制当前翻译/校对任务中的模型请求数。机器翻译 RPM 窗口保存在进程内，应用进程重启后会重新计数；它是客户端请求节流，不代表供应商侧配额保证。AI 按条目数、请求并发与请求间隔调度。
- `translation_service_profiles.task_settings_json` 由 schema v9→v10 增加；翻译与 AI 校对的任务 JSON 快照同时保存这些参数。自定义参数引用由 schema v10→v11 增加；无效或损坏的任务设置回退到对应服务类别的默认值。

### 稳定性与供应商生命周期

- 必应、有道网页和 Google 网页 adapter 依赖网页接口/会话流程，没有稳定的公开机器翻译 API 协议。页面结构、令牌字段或访问限制变化可能使 adapter 失效。此实现来自协议观察，没有复制 StarFlow 源码或引入其依赖。StarFlow 仅作在线/本地翻译流程和供应商范围参考，见 [StarFlow 仓库](https://github.com/xujunjiex/StarFlow)；它使用 LGPL-3.0，因此本项目未集成其源码或二进制。
- 腾讯云已公告：2027-01-31 停止新销售、2027-07-31 停止全面支持和续订、2030-12-31 停止所有服务。公告表示现有付费服务可在有效期内使用；接入仅面向仍有权限的 TMT 账户。见[腾讯云退市公告](https://cloud.tencent.com/announce/detail/2482)。
- DeepL Free/Pro 主机根据 Free Key 的 `:fx` 后缀选择固定官方域名。任务快照只保存配置修订和 `secretRef`，不会复制 API Key。
- 项目术语表随任务快照提供给 adapter。OpenAI Chat Completions、OpenAI Responses 与 Gemini 请求体携带结构化术语条目；DeepL 以 `context` 字段提供术语上下文；Yandex 最多发送 50 对术语。其它 15 个机器翻译 adapter 当前不发送项目术语表，需使用供应商原生术语库的能力尚未接入。华为云接口文档标注日语支持将逐步下线；该服务仅固定 cn-north-4，本地合成回归不验证区域/语言的线上可用性。

- 本项目仅借鉴 LunaTranslator 的服务分类和候选清单，没有复制其源码或引入依赖；该项目源码许可证为 GPL-3.0，见 [LunaTranslator 仓库](https://github.com/HIllya51/LunaTranslator)。其网页翻译组与传统 API 组分开维护；网页组没有纳入当前支持声明，以免把随网页变更的非固定协议误认为稳定 API。

## 密钥与备份

- 服务凭据由翻译域专用 Android Keystore AES/GCM 别名加密，写入 `translation_service_secrets.xml`；该文件排除云备份和设备迁移。Room 档案只保存 `secretRef`，不保存密钥、AK/SK、App ID/Secret、SecretId/SecretKey 或 Azure Region。
- 多字段凭据使用版本化 provider bundle，仅在加密前内存组装；解密失败返回 `SECRET_UNAVAILABLE` 并保留密文。任何服务/任务快照、导出、普通 Room 字段、日志和错误详情都不包含密钥值。
- 用户保存新凭据时需填写完整凭据组；编辑时全部留空会保留现有密文。删除档案后仅清除不再被任务快照引用的密文版本。

## 批次、响应与取消

- `TranslationBatchTaskProcessor` 先遵循全局批次上限，再取各 adapter 的批次上限；单条协议每条文本单独提交检查点。供应商 API 若不接收 TYN 条目 ID，则 adapter 按同一请求内的输入顺序将结果绑定回稳定条目 ID；数组接口检查缺失、额外响应和空译文。对支持 ID 的 AI 协议仍按稳定 ID 检查缺失、重复、未知条目。
- 译文经 `TranslationTextIntegrity` 检查控制码、格式占位符和换行。有效结果与失败条目可部分提交，翻译结果与检查点在同一 Room 事务提交。供应商协议无法提供输入顺序外的稳定 ID，因此不能验证供应商内部是否重排相同文本。
- 翻译域自有 OkHttp transport：连接/读/写/整体超时有上限、自动重定向与连接失败自动重试关闭、响应体上限 2 MiB。协程取消调用底层 `Call.cancel()`；鉴权、限流、额度、服务端和格式错误映射为类型化错误，不做无界自动重试，用户可显式重试失败或未完成条目。
- 传统机器翻译可选能力只有 `TRANSLATE`。AI 校对服务选择器依据 `AI_PROOFREAD` 能力过滤，机器翻译服务不会出现。

## OpenAI、Gemini 与 Anthropic AI adapter

- OpenAI-compatible adapter 在已配置根地址下调用 `/models` 与 `/chat/completions`；Key 只走 Bearer 请求头。每请求最多 50 条，任务处理器批次上限为 30 条。
- OpenAI Responses adapter 固定 `https://api.openai.com/v1`，调用 `/models` 与 `/responses`，Key 只走 Bearer 请求头；请求将 `store=false`，从已完成 response 的 assistant `output_text` 提取协议内容，再按稳定条目 ID 进行结构与占位符校验。Responses base URL 拒绝非官方主机、非 HTTPS、自定义端口、查询参数和其他版本路径。
- Gemini Interactions adapter 固定 `https://generativelanguage.googleapis.com`，模型目录使用 `/v1beta/models` 分页，交互使用 `/v1/interactions`，Key 只走 `x-goog-api-key` 请求头；请求设置 `store=false` 与 `stream=false`。
- Anthropic Messages adapter 固定 `https://api.anthropic.com`，模型目录使用 `/v1/models` 的 `after_id` 游标分页，消息请求使用 `/v1/messages`；Key 只走 `x-api-key` 请求头，发送 `anthropic-version: 2023-06-01`。`max_tokens` 为必填，未设置时使用 TYN 的 4096 输出上限。
- 四种协议的翻译/校对请求按稳定 ID 返回结构化结果，并验证控制码、占位符和换行。校对建议、问题、条目状态和检查点在同一事务提交，不覆盖当前译文。

## 回归与尚未完成的验收

- JVM 合成回归覆盖 17 种机器翻译 adapter 和四种 AI 协议的请求地址/头/体、签名结构、固定主机限制、密钥不进 URL、Responses/Anthropic URL 限制与响应解析、网页令牌/会话解析、语言/结果映射、Yandex 术语、能力过滤和格式完整性；任务设置回归覆盖默认值、校验、序列化、批次拆分、节流与任务快照。没有使用真实供应商凭据。
- AI 参数与提示词回归覆盖四种协议的请求体映射、结构化输出模式、自定义头/请求体的类型校验与协议字段保护、密文参数引用快照往返以及旧版快照默认兼容；没有验证具体模型、账号或服务商是否接受全部可选参数。
- 这些测试不证明真实接口账号权限、服务端变更、实际语言质量、额度策略或网络地区可用性。必应网页接口尤其需要实网观察；腾讯 TMT 有退市时间表；手机/平板上的服务配置、Keystore 和后台网络行为仍需设备验收。
- 仍未实现自动重试调度、Vertex AI 等额外 AI 协议、LunaTranslator 网页翻译组中的其它来源、本地模型、其它引擎 extractor/exporter，或 TYN 应用内运行时译表加载与交付。AI 校对范围默认值仍由工作台逐次要求用户选择，不在本文改成默认决策。
