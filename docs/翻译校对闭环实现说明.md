# 翻译校对闭环实现说明

状态：本地规则、按协议能力选择 AI 校对服务、建议/问题记录和人工处理已实现。当前 OpenAI Chat Completions、OpenAI Responses 与 Gemini adapter 声明 AI 校对能力；17 种机器翻译适配器只声明翻译能力。合成协议回归见[翻译服务配置与协议适配实现说明](翻译服务配置与协议适配实现说明.md)。真实服务、真实游戏与设备验收尚未完成。

## 数据与任务

- 翻译工作台当前使用独立 Room schema v11。项目保存本轮校对完成时间；条目保存 `UNREVIEWED`、`AI_REVIEWED`、`PROOFREAD_FAILED` 或 `CONFIRMED` 状态，以及最近处理它的 AI 校对任务 ID。
- `translation_proofread_suggestions` 保存 AI 建议译文和 `PENDING` / `ACCEPTED` / `DISMISSED` / `SUPERSEDED` 状态。当前译文只在用户点击「应用建议」或人工编辑后才变化。
- `translation_review_issues` 保存 `RULE` 或 `AI` 来源、问题类型、严重级别、任务引用及 `OPEN` / `RESOLVED` / `IGNORED` / `SUPERSEDED` 状态。问题类别由 UI 映射成本地化文案，不把服务返回文本当错误文案展示。
- AI 校对是 `AI_PROOFREAD` 后台任务，与提取和翻译任务共用 WorkManager 全局串行 drain。每批建议、问题、条目状态、进度和检查点在同一 Room 事务提交；取消、进程回收或服务失败保留已提交结果。重试只选未完成或失败条目，并沿用旧任务的协议、配置修订、模型、语言、范围、提示词、术语表和 `secretRef` 快照。
- 任务快照不保存 API Key。AI adapter 的校对输出必须按稳定条目 ID 返回建议与问题类别；重复/缺失 ID，以及占位符/控制码或换行损坏按条目标记失败，未知返回 ID 写入任务级失败标记。机器翻译服务不具备校对能力，不会进入校对服务选择器。已通过校验的建议不覆盖当前译文。

## 本地规则与人工操作

- 本地检查不创建后台任务，幂等刷新当前未处理规则问题；目前检查缺少译文、格式占位符/控制码不一致和换行不一致，不做语义判断。
- 校对工作区提供全部、待确认、有问题筛选。人工编辑、确认当前译文、应用建议、解决/忽略问题与完成本轮校对均为用户直接操作，不创建任务。
- 校对条目列表显示序号、原文、当前译文和确认状态，并与筛选共用同一条目集合。手机从列表进入条目详情，系统返回和顶栏返回回到列表；平板同页显示条目列表与详情编辑区。筛选和条目状态沿用同一套 repository 与 UI 状态，不复制校对业务逻辑。
- 页面使用公共二级顶栏与透明 Miuix Scaffold；手机列表/详情切换走公共 `BlurCrossfade`，平板列表使用稳定条目 ID 和 `listItemMotion`。
- 编辑译文后条目回到待确认状态并刷新本地规则问题。确认当前译文会解决该条目已打开的问题并关闭未处理建议。应用建议只替换译文，不自动确认，也不自动关闭问题。
- 用户可在校对工作区手动标记本轮完成；后续编辑、规则检查或新 AI 结果会撤销完成标记。

## 服务能力与范围

- OpenAI Chat Completions、OpenAI Responses 与 Gemini Interactions adapter 声明 `TRANSLATE` 与 `AI_PROOFREAD` 能力；必应、小牛、火山、Azure、DeepL、百度、腾讯 adapter 仅声明 `TRANSLATE`。选择器只显示已启用、配置完整且 adapter 能力匹配的档案；机器翻译因此不会进入 AI 校对选择器。
- 每次开始 AI 校对都必须选择「仅规则命中条目」或「全部已翻译条目」，没有默认选项。这样保留了设计文档中待产品确认的默认范围决策。
- 服务设置档案单独保存 AI 校对提示词。任务启动后使用该修订和术语表快照，不因服务后续改动或停用而切换配置。

## 验证与限制

- JVM 回归覆盖本地规则结果、校对快照密钥引用、AI 稳定 ID 解析、格式损坏拒绝和机器翻译能力排除；AI 校对快照还固定任务设置。Room 提供 v5→v6 至 v10→v11 的显式迁移与 schema 导出；v10→v11 为服务档案添加加密自定义请求参数的 `custom_parameters_ref` 引用。
- 尚未连接真实 OpenAI 兼容服务商、未用真实游戏验证校对效果，也未进行 Android Keystore、SAF、手机/平板视觉与无障碍设备验收。
- 当前工作区没有 `TranslationCatalog` / `TranslationMapProvider` 或 engine 侧译表订阅通路。MTool JSON 仍只是用户选择位置的导出文件，不表示 TYN 已能在游戏运行时加载或通过游戏内显示验收。
